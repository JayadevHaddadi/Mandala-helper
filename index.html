How to Use the Mandala Point Counter

About Mandala

Mandala is a two-player card game with 6 colors (Red, Green, Blue, Yellow, Purple, Orange). Each color has cards numbered 1-9.

Scoring Rules

  • For each color, you score points equal to the number of unique cards you have in that color.
  • Example: If you have 3 red cards, you score 3 points for red.
  • Your total score is the sum of points from all colors.

How to Use This Tool

  1. Click the + button next to a color to add a card of that color for that player.
  2. Click the - button to remove a card.
  3. The counter shows how many cards each player has for each color.
  4. Scores are automatically calculated and displayed.
  5. Use the Reset Game button to start over.

Tips

  • Count cards as they enter each player's mountain (scoring pile).
  • The maximum number of cards per color is 9.
  • You can enter custom player names for easier tracking.
