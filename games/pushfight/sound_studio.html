Board Game Arena Audio Studio

Push Fight Sound Studio

Audition and fine-tune the procedural Web Audio effects used in the game client.

Where are the sounds in the repo?
They are located in games/pushfight/bga/modules/js/Game.js (lines 6–90) inside the SoundController class. Rather than loading external .mp3 files over the network, they are synthesized mathematically in real-time using the browser's Web Audio API (AudioContext oscillators). This guarantees zero loading lag, instant response, and zero network bandwidth!
♟
1. Piece Slide
Triggered when any piece slides smoothly across empty board squares during the Move Phase.
Type: Sine | 220Hz → 140Hz | 120ms
💥
2. Push Impact Thud
Triggered on the mandatory King push. Low, physical wood-on-wood impact vibration.
Type: Triangle | 160Hz → 45Hz | 180ms
⚓
3. Anchor Bell
Clear, resonant metallic chime when the red Anchor lock is placed on the pushing King.
Type: Sine | 587.33Hz (D5) | 350ms
⚡
4. Real Push Sequence
Simulates the exact game sequence: the heavy push thud immediately followed by anchor lock.
Combo: Thud + 220ms + Anchor Bell
🏆
5. Victory Fanfare
Triumphant rising 4-note C-major arpeggio played when a player pushes an opponent piece off the board and wins.
Notes: C4 (261Hz) • E4 (330Hz) • G4 (392Hz) • C5 (523Hz) | 480ms
